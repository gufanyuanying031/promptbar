# Changelog

## 0.15.0

First public preview, based on local iterations 001–014. Adds English / Simplified Chinese UI selection, localized controls/status, and floating icon hints. Includes original/result switching, style re-optimization, clipboard feedback, clearing, animations, independent capsule/editor placement, API adapters, Keychain and local history.

The public build removes development geometry logging and fixes build metadata. Earlier local iteration numbers were not public GitHub releases.

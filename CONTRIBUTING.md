# Contributing

Open an issue with the app version, macOS version, display layout, steps, expected behavior and actual behavior. Redact API keys and private prompts. Reproduce using a harmless sample when possible.

Before submitting a change, run `zsh Source/build.sh` and `zsh scripts/test.sh` on macOS. Explain which UI paths you actually tested. Do not label mocked HTTP or geometry checks as live API or UI validation. Please discuss larger feature changes first.

For credentials or private security details, do not publish them in a public issue. Use the repository owner's GitHub profile to find an appropriate private contact route.

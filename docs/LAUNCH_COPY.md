## English — short post

I built PromptBar, a small native macOS utility for polishing prompts without leaving your workflow.

Copy → refine with your own API key → restore or copy back. A white floating capsule, English/Chinese UI, style switching, local history, and no automatic message submission.

It’s an open-source early preview for Apple Silicon. Not notarized yet; feedback and reproducible bug reports are welcome.

https://github.com/gufanyuanying031/promptbar

## English — community introduction

**Show: PromptBar — a floating prompt editor for macOS with bring-your-own API keys**

I often write a rough prompt in one app, move it elsewhere to refine it, and paste it back. PromptBar turns that into a small clipboard workflow: open a floating editor, choose a style, optimize through your provider, compare with the original, then copy back.

Built with SwiftUI and AppKit, with English and Simplified Chinese UI. Supports OpenAI-compatible, Anthropic Messages and Gemini endpoints. Keys stay in Keychain; history stays in local JSON. The capsule and editor are separate windows so fitting the editor to the screen does not move the capsule.

This is an early preview: Apple Silicon only, no notarization or automatic updates yet, and broader UI/OS testing is still needed. It does not inject into other apps or guarantee a better prompt. I’d appreciate feedback on whether this small workflow is useful and where the interaction breaks down.

Source and download: https://github.com/gufanyuanying031/promptbar

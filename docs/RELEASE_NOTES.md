# PromptBar v0.15.0 — bilingual early preview

A small native macOS prompt editor with English / Simplified Chinese UI, bring-your-own API keys and a fixed floating capsule.

- Language selection in Settings; default follows your system.
- Small floating action labels on editor buttons, plus press and copy/paste feedback.
- Optimize, restore original, change styles to re-optimize, and clear or copy with one click.
- Separate editor panel, long-text editing, progress ring, and animated opening/closing.
- OpenAI-compatible / Anthropic / Gemini adapters; keys in Keychain; local history.

**Apple Silicon · macOS 14+ deployment target · early preview.** The ZIP is ad-hoc signed, not Developer ID signed or notarized. macOS may block downloaded builds. Build from reviewed source if preferred. Full UI and minimum-OS matrix validation remain incomplete. Requests may incur provider charges.

Install: extract the ZIP, move the app into Applications, quit older copies, launch, then Settings → configure language, provider, model ID and API key. See the bilingual guides in the repository. `SHA256SUMS.txt` covers the downloadable archives.

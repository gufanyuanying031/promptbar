# PromptBar 使用指南

## 安装与配置

从 GitHub Release 下载 arm64 ZIP，解压后把 App 放进“应用程序”，先退出旧副本。Apple Silicon、构建目标 macOS 14+；预览版仅 ad-hoc 签名，未通过 Apple 公证，下载后可能被系统拦截。也可以审查源码后本地构建。

右键胶囊或菜单栏星星 → 设置。顶部选择 **English / 简体中文**，立即生效并记住选择，默认跟随系统语言。界面语言不会翻译你的提示词。

在“模型与 API”选择厂商，核对 HTTPS Base URL、API 协议、精确模型 ID，填写 Key 后保存。不同厂商独立保存 Key。测试连接会发送一条可能计费的小请求。DeepSeek 默认 `deepseek-flash`，也可选择 `deepseek-v4-pro`；不要把模型显示名称当作 API ID。

## 胶囊三个区域

- 左侧六点：按住拖动，移动时关闭编辑面板，松手不会自动展开。
- 中间三颗星：悬停展开，点击进入编辑。
- 右侧图钉：控制窗口最前，不等于保持展开。

编辑面板独立在上方或下方打开，适应屏幕边界时不移动胶囊。右键进入设置、条目库和退出。

## 展开栏从左到右

风格 → 输入框 → 长文展开 → 清空 → 粘贴 → 复制 → 锁定展开 → 优化。

鼠标放在图标上显示小浮签，按下时有反馈。粘贴／复制后短暂显示勾选。

- **切换风格**：非空输入时自动重新优化，优先使用原文快照；手动编辑后使用当前草稿。选择相同风格不重复请求。空白自定义规则会提示错误。
- **清空**：移除本次内容、原文／结果快照和补充要求；不删除历史。
- **粘贴**：直接替换草稿，不再询问。
- **优化**：最右侧星星发出 API 请求，转圈表示进行中，再点取消。成功后按钮还原原文，再点切回优化稿，不重复请求。
- **继续优化**：右键选择再次优化，或输入补充修改要求。
- **手动编辑**：建立新草稿，清除旧原文切换快照，避免覆盖手工修改。

鼠标离开星星和编辑面板约 650ms 后动画收起。长文模式也会收起；锁定展开、优化中、菜单打开和设置等状态有保护。设置里可减少动态效果。

快捷键：Control + Option + P 展开／收起；Command + Return 优化／原文切换。快捷键占用时用菜单栏入口。

## 历史、隐私和卸载

条目库可搜索、载入、置顶、复制、删除，导入／导出 JSON，以及清空未置顶历史。最多 150 条未置顶记录，置顶条目保留。自动历史可在设置关闭。导入只支持本应用格式。

历史与设置：`~/Library/Application Support/PromptBar/`，历史为未加密 JSON。Key 在系统钥匙串服务 `app.promptbar.native.v1`，导出不带 Key。无遥测或自建中转，提示词和认证信息发送到你配置的 API。

退出时草稿不自动保存，重要内容请先复制。卸载时退出 App，删除 App，可选删除数据目录和对应钥匙串条目；卸载不会撤销厂商 Key。

## 常见问题

旧界面还在：先退出所有旧版，避免同名副本并行。没有 Dock 图标是正常行为，使用菜单栏退出。

接口错误：核对余额、Key、模型 ID、协议与 Base URL；模型可用性取决于厂商和账号。错误与取消保留当前文字。

输出变差：还原原文，调整风格后重试。优化不是质量保证，发送前检查事实和约束。

提交 Issue 时附版本、系统、显示器布局和复现步骤，删除 Key 与私人提示词。完整技术限制见 README 和验证说明。
